# Verification at stack stage 5/8

This branch introduces **Assemble complete GPU scenes with bounded allocation**. The original SVG demo remains
available from the repository root until the final migration.

```sh
npm ci
npm test
npx vgpu install-software-renderer
VGPU_ADAPTER=software npm run check:shaders
VGPU_ADAPTER=software npm run test:gpu
VGPU_ADAPTER=software npm run test:visual
```

Native checks require an available adapter and fail when none exists. Software
GPU execution establishes correctness only; no hardware speedup is claimed.

Coverage available in this branch:

- noise interpolation against 260 captured samples.
- 18 brush cases / 448 generated points and bounds.
- ordered blending, white masks, open paths, winding, caps and joins.
- nine CPU terrain constructions, 96 independent island layouts, overflow checks.
- neighbor-aware planning, seed 1 regression, repeated and overlapping ranges.
- all eight trees, command/control overflow, original references and 775 controlled CPU commands.
- 13 independent motif constructions and three intentional overflow cases.

Artifacts are written under `test-results/gpu-primitives/`. Coordinate tolerances
and comparison details are reported by each independent probe. Expected CPU
data in `tests/fixtures/` is frozen and is not regenerated by acceptance tests.
